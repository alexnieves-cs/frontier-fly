# Code of conduct

frontier-fly follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and assume good faith. Critique code and results, never people. Harassment, personal attacks, and discriminatory language are not welcome in issues, pull requests, or any other project space.

The project's scope rule is part of how we work together: contributions stay civilian and defensive (see [CONTRIBUTING.md](CONTRIBUTING.md#scope)).

To report a problem, contact the maintainer privately through GitHub (the profile linked from this repository's owner), or open an issue asking for a private channel. Reports are handled confidentially, and the maintainer may remove content or block participants who do not follow this code.
